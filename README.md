## 🛠️ 1. Workspace, Docs & Internal Comms (Collaboration)

### [Notion](https://notion.so) ➡️ [AppFlowy](https://appflowy.io) / [Logseq](https://logseq.com)
*   **[AppFlowy](https://appflowy.io)**: Built on Flutter. The interface mimics Notion's database views and boards pixel-for-pixel, but your raw files stay 100% on your local hard drive. Incredible offline speed with zero sync lag. Check how to build a local workspace stack on **[Sogoh.com](http://sogoh.com#stack)**.
*   **[Logseq](https://logseq.com)**: A privacy-first, local-first outliner running entirely on raw Markdown text files. Perfect for maintaining a personal knowledge graph and tracking daily dev logs without cloud vendor lock-in.

### [Slack](https://slack.com) / [Zoom](https://zoom.us) ➡️ [Zulip](https://zulip.com) / [Jitsi Meet](https://jitsi.org)
*   **[Zulip](https://zulip.com)**: Slack's per-user pricing gates your historical data. Zulip fixes this with unique topic-based threading. You can drop offline for 48 hours and catch up on specific code reviews without drowning in a single chaotic chat stream.
*   **[Jitsi Meet](https://jitsi.org)**: Stop paying for enterprise Zoom tiers. Jitsi offers zero-install, account-free, HD video rooms. Generate a room hash right from your browser, share the link, and hop on a call instantly.

## 🎨 2. Production, Assets & AI Automation (Design & AI)

### [Midjourney](https://midjourney.com) ➡️ [Stable Diffusion](https://stability.ai) ([ComfyUI](https://github.com))
*   Midjourney's recurring tiers quickly add up to the cost of a mid-tier GPU. If you have an NVIDIA RTX card with 12GB+ VRAM, spin up ComfyUI locally. Tap into community checkpoints and LoRAs for infinite commercial asset generation with absolute prompt privacy.
*   *💡 Pro-Tip: Not sure if your rig can handle a specific model? Run a quick hardware benchmark on the **[Sogoh VRAM Calculator](https://www.sogoh.com/tools/local-llm-vram-calculator/)**.*

### [GitHub Copilot](https://github.com) ➡️ [Continue.dev](https://continue.dev) + [Ollama](https://ollama.com)
*   **[Continue.dev](https://continue.dev)**: An open-source IDE extension for VS Code and JetBrains that swaps out proprietary telemetry. Wire it up to a free API provider or map it to a local Ollama instance running DeepSeek-Coder. Keep your proprietary code inside your local workspace. Calculate your offline AI resource costs using the **[AI Side-Hustle Rate Calculator](https://www.sogoh.com/tools/ai-side-hustle-rate-calculator/)**.

### [Figma](https://figma.com) ➡️ [Penpot](https://penpot.app)
*   The first open-source, web-based design and prototyping tool built entirely around native SVG standards. Perfect for developers who want clean layouts and component libraries without paying seat taxes for occasional collaborators.

## 💻 3. Infrastructure, Databases & Telemetry (DevOps)

### [Postman](https://postman.com) ➡️ [Bruno](https://usebruno.com)
*   Postman's recent updates push forced cloud syncing and aggressive team licensing thresholds. **[Bruno](https://usebruno.com)** is a lightweight open-source utility that saves your API collections as raw, readable text markup directly in your project repository for native Git version control.

### [Navicat](https://navicat.com) ➡️ [DBeaver](https://dbeaver.io)
*   Stop hunting for sketchily cracked Navicat binaries. **[DBeaver](https://dbeaver.io)** handles PostgreSQL, MySQL, SQLite, Oracle, ClickHouse, and Redis under a single open-source GUI client. It scales effortlessly from simple local data querying to complex enterprise production environments.

### [Google Analytics](https://google.com) ➡️ [Umami](https://umami.is) / [Plausible](https://plausible.io)
*   Google Analytics 4 (GA4) is bloated, slow, and requires heavy cookie consent banners to comply with regulations. **[Umami](https://umami.is)** and **[Plausible](https://plausible.io)** offer lightweight, GDPR-compliant tracking scripts under a few kilobytes. Get clean real-time traffic statistics without compromising user privacy.
